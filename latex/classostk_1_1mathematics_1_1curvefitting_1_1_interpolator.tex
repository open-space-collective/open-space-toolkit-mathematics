\mbox{\hyperlink{classostk_1_1mathematics_1_1curvefitting_1_1_interpolator}{Interpolator}} (abstract class)

Check whether a vector of x values is uniformly spaced. 

Interpolators that have both a uniform and a non-\/uniform implementation use this to decide which one to build. A vector counts as uniformly spaced when every one of its values lies on the reconstructed grid x0 + i $\ast$ h, where h is the mean spacing, to within a tolerance that accounts both for a small slack relative to the total span and for the precision with which the values themselves can be represented.
