Detailed Description

Interpolator (abstract class)

In mathematics, an interpolator is a type of estimator allowing to construct new data points based on a range of a discrete set of known data points.

auto interpolator = Interpolator::GenerateInterpolator(Interpolator::Type::Linear, x, y);
double value = interpolator->evaluate(1.5);

bool ostk::mathematics::curvefitting::Interpolator::IsUniformlySpaced ( const VectorXd &  anXVector)
staticprotected

Check whether a vector of x values is uniformly spaced.

Interpolators that have both a uniform and a non-uniform implementation use this to decide which one to build. A vector counts as uniformly spaced when every one of its values lies on the reconstructed grid x0 + i * h, where h is the mean spacing, to within a tolerance that accounts both for a small slack relative to the total span and for the precision with which the values themselves can be represented.

const bool isUniform = Interpolator::IsUniformlySpaced(x);
Parameters
anXVectorA vector of x values, sorted in ascending order
Returns
True if the x values are uniformly spaced
